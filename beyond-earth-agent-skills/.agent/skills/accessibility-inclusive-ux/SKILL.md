# Accessibility Inclusive Ux Skill

## Scope
Navigation, carousel, dialogs, forms, quizzes, simulations, status indicators, motion and responsive layouts.

## Procedure
- Target WCAG 2.2 AA while documenting any criterion that cannot be met.
- Test keyboard-only navigation, visible focus, logical focus order and escape behavior.
- Ensure dialogs trap focus, restore focus and expose correct accessible names and descriptions.
- Provide pause/stop controls for auto-advancing or moving content; pause on focus and hover where appropriate.
- Respect reduced-motion settings while preserving access to information and controls.
- Never communicate status through color alone.
- Check text and non-text contrast, zoom/reflow, touch target sizes and semantic landmarks.
- Ensure charts, 3D scenes and canvas content have equivalent textual or 2D alternatives.
- Test mobile layouts and screen-reader labels for icon-only controls.

## Acceptance
No keyboard traps or inaccessible autoplay; core tasks work with keyboard and assistive technology; responsive layouts remain complete.
